# PaperBell AI 辅助迁移版

适用：将 PaperBell 4.6.1 的个人内容迁入 5.0.3，保留新版默认插件、模板、脚本与预设。先备份旧库，每次一个文件夹，按新版结构适配并检查。

## 包内文件

- `paperbell-migrate/SKILL.md`：Agent 执行入口。
- `paperbell-migrate/references/paperbell-rules.md`：详细迁移规则。
- `paperbell-migrate/references/operation-playbook.md`：具体替换和转换方法。
- `paperbell-migrate/references/step-checks.md`：验收条件。
- `paperbell-migrate/scripts/inventory.py`：可选只读盘点工具，不会迁移文件。

请保留整个 paperbell-migrate 文件夹，不要只提供 SKILL.md 而遗漏引用资料。无需运行 scripts 中的工具即可阅读规则；执行 Python 工具时才需要 Python 环境。

## 使用方式

使用能访问本地文件的 Agent，例如 Codex。可按工具自身的技能安装方式安装整个文件夹，也可直接让 Agent 阅读本地 SKILL.md 及其引用文件。普通网页聊天收到说明后不会自动获得你的磁盘访问权限。

先准备旧库完整备份和独立新版库；备份与迁移记录放在两个笔记库之外。干净新版可重新下载时无需强制整库备份，但即将覆盖的新库个人文件仍需备份。不要公开分享自己的笔记库、备份、账户信息或迁移记录。

将下面请求中的占位内容替换为自己的实际路径，发送给 Agent：

```text
请读取 <本包绝对路径>/paperbell-migrate/SKILL.md，并按其引用读取详细规则和操作手册。

旧库：<旧库绝对路径>
新版库：<新版库绝对路径>
旧库备份：<备份绝对路径；没有则先创建并核验>
迁移记录：<两库之外的本次记录目录>

先只读核对目录、备份和差异，报告本次计划。
获得我确认后，每次只迁移一个文件夹，完成新版格式适配和检查后等我继续。
旧库不修改、不剪切。保留新版系统默认，只迁个人内容、Bib 和必要附件。
项目及 Longform 的目录、字段、Base 引用、作者元数据和工作流一起适配。
文献保留 concepts 并追加干净 keywords；Links、Places 和用途不明内容先列待选。
导出暂缓，不安装工具或恢复旧工作流。不要将示例身份和路径当我的真实资料。
```

## 每步看什么

要求 Agent 给出源和目标、实际改动、核对结果、未验证项与下一步。只有你确认后才进入另一文件夹。同名冲突、进度矛盾、Bib 同 key 不同条目不能静默覆盖。

## 换对话或继续迁移

提供本次记录目录，让 Agent 先读 state.json、逐文件清单、最近结果和未迁移清单，再核对磁盘实际状态。不要从头重跑，不自动补迁已暂缓内容。

## 完成标准

个人资料有去向，旧库不变，必要路径和新版格式正确；暂缓文件及缺失外部资源列清单。配置通过不代表 PDF、Word 或 Obsidian GUI 已实测，未验证的必须明确保留。

本包是通用资料，不含笔记库、个人备份、历史进度或绑定某次迁移的一次性脚本。可将整个“AI辅助迁移版”文件夹直接分享给他人。
